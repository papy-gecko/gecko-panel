# Politique de sécurité

## Versions supportées

| Version | Supportée |
|---------|-----------|
| 1.0.x   | ✅        |

## Signaler une vulnérabilité

Si vous découvrez une vulnérabilité de sécurité dans Gecko Panel, **ne créez pas d'issue publique**.

Contactez-nous directement par email : **ltitan.tox@gmail.com**

Merci d'inclure dans votre rapport :
- Une description détaillée de la vulnérabilité
- Les étapes pour reproduire le problème
- L'impact potentiel
- Si possible, une suggestion de correctif

Nous nous engageons à :
- Accuser réception sous **48h**
- Vous tenir informé de l'avancement du correctif
- Publier un correctif dans les meilleurs délais
- Vous créditer dans le changelog si vous le souhaitez
